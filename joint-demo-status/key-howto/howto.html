Add the SPS read key (demo gateway)

About 3 minutes. Steps 2 and 3 must happen within 10 minutes of each other.
1
Open the Self Client
Go to api-console.zoho.com, signed in as itexe@ (SmartPack), and open Self Client.
On the Client Secret tab, keep the Client ID and Client Secret ready to copy.
2
Generate a code 10-minute timer starts
Open the Generate Code tab. In Scope, paste exactly: ZohoInventory.salesorders.READ,ZohoInventory.items.READ,ZohoInventory.compositeitems.READ Time duration: 10 minutes. Description: demo gateway read. Click Create, choose SmartPack, and copy the code.
3
Run the setup in your own SSH terminal
Use PuTTY or Terminal. Don't use the Claude prompt, because the script asks questions. bash /root/tools/demo-key/set-read-key.sh Paste the Client ID, the Client Secret and the code when it asks. The last two stay hidden while you paste.
4
Check the answer
“Saved … Now tell Claude: fixed”: done. Tell Claude fixed.
“invalid_code”: the code expired or was used already. Go back to step 2.
“invalid_client”: the Client ID or Client Secret was mistyped. Run step 3 again.
Why the 10 minutes doesn’t matter later: the code is used only once. The script trades it for a refresh token that doesn’t expire. The script rewrites the key file with the right names, adds fresh demo-only values, and locks the file. Nothing secret is printed.
Never paste the secret or the code into the Claude chat.
