# Order Portal + Production Dashboard

This folder keeps the papers for two projects:

- **Order Portal**: sales staff send customized orders, and the production team accepts them.
- **Production Dashboard**: managers see every production job and its steps.

There is **no app code here**, only plans, designs, demos and notes.
The app code was lost from the server.

## What is in each folder

| Folder | What it holds |
|---|---|
| `specs/` | The written plans for both apps (start here) |
| `plans/` | The step-by-step build plan for the dashboard |
| `demo-plan/` | The joint demo plan from 21 Oct, with the roadmap and PDFs |
| `joint-demo-status/` | The build status page from 28 Oct and the start-up scripts |
| `portal-demo/` | A clickable demo of the portal, from 18 Oct |
| `portal-history/` | The customized items catalogue, plus old portal plans (`superseded-...` = no longer used) |
| `dashboard-history/` | Early dashboard notes, manager demos, mockups and decisions (Sep–Oct) |
| `research/` | Notes on how Zoho stores the data |
| `notes/` | Short notes and briefs |

## Where to start

1. Read `specs/2026-10-24-joint-demo-v0-1-rev4-demo-first.md`. It is the latest plan.
2. Open `joint-demo-status/Joint-Demo-Build-Status.html` in a browser to see how far the build got.

## Good to know
